# $5 Notary North

One-page booking site for Yelp / Google Business.

**Live site:** https://cottonandcolor.github.io/5-notary-north/

## Local preview

```bash
python3 -m http.server 5173
```

Open http://127.0.0.1:5173

## Yelp

1. Paste the live URL into your Yelp Business **Website** field
2. Use `YELP_PASTE.txt` for About, specialties, and review replies
